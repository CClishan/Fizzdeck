# FizzDeck 原生色彩规则

颜色用来指路。状态和项目身份都要有文字或图标，不能只靠颜色区分。下列比例是逐屏视觉预算，用浅、暗实机截图检查。

| 层 | 预算与用法 |
| --- | --- |
| 中性骨架 | 约 85–90%。页面、卡片、侧栏、次要动作和工具/类型/技术栈徽章走灰阶。选择态用 `selectedFill` 或 `elevatedFill`，前景用 `.primary`。`FizzSegmentedCapsule` 不接受自定义选中色。 |
| 重点 | 小于 5%。每个操作区只有一个主动作，优先用 `FizzActionButton(prominence: .primary)`；同屏有「继续对话」时，复盘入口和其他动作保持中性。紫色也可用于键盘焦点、当前拖放目标。常规导航、KPI 折线和装饰图标不使用重点色。 |
| 语义状态 | `statusDanger` 表示失败或阻塞，`statusWarning` 表示需要关注，`statusSuccess` 表示成功或运行中。限 6pt 圆点或 10–12% 透明度的轻胶囊。正文和大面积提示底保持中性；原生确认对话框保留系统的 destructive 语义。 |
| 项目与数据 | `ProjectAccentColor` 是唯一多色盘，供项目、用户指定颜色和分组的识别点，以及项目图表使用。同屏只让一块图表承担色彩主角：工作台用周历，复盘用项目趋势，其余折线、活跃节奏和费用构成用灰阶。长周期提交热力图单独打开，用 `accent` 的透明梯度。 |

| Token | 浅色 | 暗色 |
| --- | --- | --- |
| `page` | `#FFFFFF` | `#111316` |
| `accent` | `#6941E8` | `#9F82FF` |
| `accentSoft` | `#6941E8`，10% | `#9F82FF`，16% |
| `statusDanger` | `#DC3848` | `#FF6B78` |
| `statusWarning` | `#CF6E0C` | `#FFA940` |
| `statusSuccess` | `#159662` | `#38D399` |

匿名分享卡的「项目 1–5」按贡献排名从项目盘取不同颜色，避免路径散列碰撞让相邻色带合并；「其他」保持中性。显示项目名时沿用项目自身的颜色。两种分享样式只给实际数据着色，零值区保留底色。

Git 与还原预览共用差异行：仅 `+` / `-` 代码文字区分增删，不给整行铺红绿底。手动项目标签只在项目图标角上显示色点；详情标题和列表选择态保持中性。

新增 RGB 定义只放在 `FizzTheme.swift` 中已声明的 Token。视图、Toast 和共用样式不直接使用系统彩虹色或自定义亮紫；品牌 Logo 仍使用原有图形资源。`FizzDesignSystemTests` 验证浅暗 Token、项目色对比度以及源码里的色值与重点色白名单。更改白名单时同步说明具体交互和颜色的用途。
