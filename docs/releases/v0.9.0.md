FizzDeck **v0.9.0（Build 23）**，适用于 Apple Silicon 和 macOS 26 及以上。

- **在一个工作台上接着做。** 打开项目就能看到上次进度、待处理事项和整周活动。用 `⌘K` 跨项目找对话，索引包括 Cursor 的本机对话记录和 OpenCode 的本机数据库。
- **并行开发与交接。** 在版本页创建、合并或移除 Git Worktree。按「换工具接着做」「丢给 AI 修报错」「写交接说明」生成接力卡，复制前自动脱敏。
- **复盘有据可查。** 对比近 7、30、90 天或全部记录的对话、时长、估算费用和 Tokens。没有日志依据的时长、轮数和测试结果留空。可复制 Markdown，或复制默认隐藏项目名的光栅／ASCII 分享卡 PNG，各有浅暗两款。
- **新的原生外观。** 浅色工作台换为纯白底与原生玻璃侧栏；Kubai 图标和更明亮的项目色标出操作与项目。随包的 Obel Mono 用于英文和数字，中文继续使用 macOS 默认字体。

**安装与校验：** 从同一 Release 下载 `FizzDeck-0.9.0-arm64.dmg` 和 `FizzDeck-0.9.0-arm64.dmg.sha256`。在下载目录运行 `shasum -a 256 -c FizzDeck-0.9.0-arm64.dmg.sha256`，看到 `OK` 后再安装。

**签名与系统快捷指令：** 本版应用使用 ad-hoc 签名，无 Apple Team ID，未经 Apple 公证。macOS 可能拒绝从「快捷指令」运行其动作；打开项目、复制接力卡和查看体检均可直接在 FizzDeck 内使用。
