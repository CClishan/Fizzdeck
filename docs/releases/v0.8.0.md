FizzDeck **v0.8.0（Build 16）**，适用于 Apple Silicon、macOS 26 及以上。

- **体检会跟上项目改动。** 前 8 个关注项目的依赖清单、锁文件或 `.env` 配置变化时，Doctor 只重检发生变化的项目。对支持的关注 Git 仓库，每个项目最多每 24 小时静默检查一次远端更新，不改工作区。非致命问题可以按项目设为不再提醒。
- **在本机排查运行问题。** 体检页列出常见开发端口、所属进程和项目；确认后可以温和停止外部监听进程。构建、类型检查和测试只在你点「试跑一下」时启动，输出和停止按钮都在日志区。新增 Go、Rust、Ruby 和 Swift 的运行时检查。
- **看懂近期进展。** 进度页可切换近 14 或 30 天的估算 AI 费用与提交趋势。规则周报留在本机；点选 AI 润色后只发送汇总数字，失败仍可复制规则版。非 Git 项目开启版本保护时会按技术栈补充忽略规则，并建立第一条可还原的基线。
- **从其他工具直达项目。** `fizzdeck://open` 可打开已纳管项目的指定页签，`fizzdeck://handoff` 可打开接力卡。版本页支持用键盘查看文件差异、暂存或取消暂存。

**安装与校验：** 下载 `FizzDeck-0.8.0-arm64.dmg` 和同一 Release 的 `FizzDeck-0.8.0-arm64.dmg.sha256`。在下载目录运行 `shasum -a 256 -c FizzDeck-0.8.0-arm64.dmg.sha256`，看到 `OK` 后将 App 拖入「应用程序」。

**签名与快捷指令：** 此 DMG 使用 ad-hoc 签名，未获 Apple 公证。首次打开可能被 Gatekeeper 拦截；如果你信任下载来源，可在「系统设置 → 隐私与安全性」为 FizzDeck 选择「仍要打开」。三个系统快捷指令在有团队签名的开发版已通过真机测试；此 DMG 没有 Team ID，macOS 可能拒绝执行这些指令。打开项目、复制接力卡和查看体检均可在 FizzDeck 内完成。
